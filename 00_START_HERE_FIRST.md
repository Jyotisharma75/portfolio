## 🛑 IF SOMETHING GOES WRONG

### "Node.js is not recognized"
```
Solution:
1. Restart your computer
2. Open NEW Command Prompt
3. Try again
```

### "Permission Denied"
```
Solution:
1. Right-click install-and-run.bat
2. Select "Run as administrator"
3. Click Yes
```

### "Port 3000 already in use"
```
Solution:
Edit run-portfolio.bat, change:
  npm run dev
to:
  npm run dev -- -p 3001

Then go to: http://localhost:3001
```

### npm install is slow
```
Normal! First setup takes 2-5 minutes
Just wait, don't close the window
```
