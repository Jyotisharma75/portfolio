🛠️ TROUBLESHOOTING:

Problem: "Node.js is not recognized"
Solution: 
  1. Restart your computer
  2. Open new Command Prompt
  3. Try again

Problem: "Permission Denied"
Solution:
  1. Right-click install-and-run.bat
  2. Select "Run as administrator"
  3. Click Yes

Problem: npm install is slow
Solution:
  1. This is normal (first run takes 2-5 min)
  2. Just wait, don't close the window
  3. Next runs will be faster

Problem: Port 3000 already in use
Solution:
  1. Edit run-portfolio.bat
  2. Change: npm run dev
  3. To: npm run dev -- -p 3001
  4. Go to: http://localhost:3001

Problem: Browser doesn't open
Solution:
  1. Look for "ready on" in console
  2. Manually open browser
  3. Go to: http://localhost:3000
