## 🛑 TROUBLESHOOTING

### ❌ "Node.js is not recognized"
```
✅ Solution:
1. Restart your computer
2. Open NEW Command Prompt
3. Run install-and-run.bat again
```

### ❌ "Permission Denied" or "Access Denied"
```
✅ Solution:
1. Right-click install-and-run.bat
2. Select "Run as administrator"
3. Click "Yes" when prompted
```

### ❌ npm install is very slow
```
✅ Solution:
1. This is NORMAL on first run
2. Takes 2-5 minutes
3. Subsequent runs are faster
4. Just wait, don't close the window
5. Download size: ~400 MB
```

### ❌ Port 3000 already in use
```
✅ Solution:
1. Find another terminal running port 3000
2. Or change port in run-portfolio.bat
3. Change: npm run dev
4. To: npm run dev -- -p 3001
5. Open: http://localhost:3001
```

### ❌ Browser doesn't open automatically
```
✅ Solution:
1. Look in console for: "ready on http://localhost:3000"
2. Open Chrome/Firefox/Edge manually
3. Type: http://localhost:3000
4. Enter
```

### ❌ Files not organizing correctly
```
✅ Solution:
1. The script creates app/, components/, data/ folders
2. If folders don't exist, script will create them
3. Run install-and-run.bat again
4. Or manually create these folders
```
