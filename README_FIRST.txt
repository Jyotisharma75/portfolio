═══════════════════════════════════════════════════════════════════════════════
                         💡 IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════════

Issue 1: "Node.js is not recognized"
→ Solution:
  1. Restart your computer
  2. Open a NEW Command Prompt window
  3. Try: node --version
  4. Run install-and-run.bat again

Issue 2: "Permission Denied" error
→ Solution:
  1. Right-click install-and-run.bat
  2. Select "Run as administrator"
  3. Click "Yes" when prompted

Issue 3: npm install is very slow
→ Solution:
  1. This is NORMAL for first run
  2. Takes 2-5 minutes
  3. Downloads ~400 MB
  4. Just wait, don't close the window
  5. Next runs will be faster

Issue 4: Port 3000 is already in use
→ Solution:
  1. Find what's using port 3000
  2. Or change port in run-portfolio.bat
  3. Change: npm run dev
  4. To: npm run dev -- -p 3001
  5. Go to: http://localhost:3001

Issue 5: Browser doesn't open automatically
→ Solution:
  1. Look in console for "ready on http://localhost:3000"
  2. Open your browser manually
  3. Type: http://localhost:3000
  4. Press Enter

See RUN_YOUR_PORTFOLIO.md for more troubleshooting
